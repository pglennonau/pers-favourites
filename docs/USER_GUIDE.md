# Pers Favourites — User Guide

Version: **0.27.23 development**

Pers Favourites is a curated list of places selected by the Owner. Ordinary users can browse without signing in.

## Browse and filter

Use the main search and filters to narrow Pers places by location, place type, cuisine, rating, distance and other available criteria.

Pers results remain the primary results.

## Broader searches

When external sources are enabled, results are shown in separate sections:

- **Pers Favourites** — the Owner's saved collection.
- **More places from Google** — live Google Places results.
- **TripAdvisor results** — live TripAdvisor results when that service is enabled.

The sources are kept separate so it is clear where each rating and listing came from.

## Ratings

A venue can show several distinct ratings:

- Pers Rating — set by the Owner.
- User Rating — average of ordinary user ratings, excluding Owner/System Administrator.
- Google rating — live/source-specific where available.
- TripAdvisor rating — source-specific where authorised and available.

These ratings are never blended into one synthetic score.

## Photos

Photo priority is:

1. approved Pers photo;
2. Google Places photo;
3. TripAdvisor photo only if no suitable Google photo is available and TripAdvisor access is active;
4. placeholder.

Provider attribution is shown with external photos.

## Your settings

My Settings includes your preferred distance radius, language and whether filters should be remembered between visits.

## Contributing photos

Where enabled, use **Add Photo** on the venue detail. User contributions require lightweight identity at the point of contribution and approval before they are visible to everyone.

## Privacy and payments

Ordinary users do not manage API accounts, payment methods or service charges. Those controls belong to the Owner/System Administrator areas.
